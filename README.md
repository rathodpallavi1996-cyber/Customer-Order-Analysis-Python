# Customer order Analysis Using Python

## Project Overview

This project analyzes customer order data using Python to understand customer spending, product purchases, and category-wise sales.

The project uses Python data structures and basic programming concepts to organize customer orders, calculate customer spending, classify customers, and generate useful insights from the available data.

## Project Objective

The main objective of this project is to analyze customer orders and identify:

- Customer spending patterns
- High-value and moderate-value customers
- Product categories and revenue
- Top spending customers
- Frequently purchased products
- Customers who purchased from different categories
- Category-wise sales trends

## Dataset

The project uses a predefined customer order dataset.

Each order contains:

- Customer name
- Product
- Price
- Product category

The dataset contains products from two categories:

- Electronics
- Fashion

Example products include Laptop, Smartphone, Headphones, Shoes, and Watch.

- Basic calculations

## Analysis Performed

### 1. Customer Order Management

Customer order information is stored using lists, tuples, and dictionaries.

A dictionary is used to organize each customer's ordered products and related information.

### 2. Customer Spending Analysis

The project calculates the total amount spent by each customer.

Customers are classified based on their total purchase value:

- Above 100 → High-value buyer
- 50 to 100 → Moderate buyer
- Below 50 → Low-value buyer

### 3. Product Category Analysis

The project maps products to their respective categories and identifies the unique product categories available in the dataset.

### 4. Category Revenue Analysis

The total revenue generated by each product category is calculated.

### 5. Top Customer Analysis

The project identifies the three customers with the highest total spending using Python sorting and a lambda function.

### 6. Product Analysis

The project identifies:

- Unique products
- Product purchase frequency
- Most frequently purchased products

### 7. Customer Category Analysis

Set operations are used to identify customers who purchased products from multiple categories and customers who purchased from both Electronics and Fashion.

### 8. Sales Trend Analysis

Category-wise revenue is sorted and the percentage contribution of each category to total revenue is calculated.

## Key Results

Based on the project dataset:

- **Electronics revenue:** 2150
- **Fashion revenue:** 300
- **Electronics contribution:** 87.8% of total revenue
- **Fashion contribution:** 12.2% of total revenue
- **Highest-spending customer:** Alice – 1200
- **Second-highest-spending customer:** Bob – 800
- **Third-highest-spending customer:** Eva – 200
- **High-value customers:** Alice, Bob, Charlie, and Eva
- **Moderate-value customer:** David

In the current dataset, each product appears once, so all five products have the same purchase frequency.
